# 帧 ID 约定（xgc 流水线通用）

全链路（IXD → ui-plan → HTML/Pixso）使用 **前缀 + 序号** 作为稳定标识。前缀表达语义类型，便于阅读与检索；序号按功能模块递增，**不按项目业务随意命名**。

## 前缀与语义类型

| 前缀 | 语义类型 | 含义 | 示例 |
| ---- | -------- | ---- | ---- |
| **P-** | Screen（路由屏） | 导航栈中的一级目的地 / 路由页面 | P-00 启动, P-01 首页, P-10 设置 |
| **H-** | State（壳屏内容态） | 挂在某个 **P-** 壳下的内容变体（列表/空/错/权限等） | H-01 骨架, H-02 列表, H-04 空状态 |
| **V-** | State（内页内容态） | 挂在某个 **子级 P-**（如 P-10）下的内容变体 | V-01 加载, V-02 详情列表 |
| **O-** | Overlay（叠加层） | Sheet、对话框、全屏蒙层交互 | O-01 底部菜单, O-03a 删除确认 |
| **G-** | Global feedback | Snackbar、Toast、Banner 等非路由反馈 | G-01 操作结果提示 |
| **DS-** | Design system | 色板、字阶、图标等设计系统页 | DS-00 配色与图标 |

### 与抽象类型的对应

- **Screen** → `P-`
- **State**（同一路由下的 UI 变体）→ `H-`（主壳）或 `V-`（内页壳）；选型规则见下
- **Overlay** → `O-`
- **Global feedback** → `G-`
- **Design system** → `DS-`

### H- 与 V- 如何选

- 态属于 **Tab/主导航根屏**（如 P-01）→ 用 **H-**
- 态属于 **push 进去的内页**（如 P-10 相册）→ 用 **V-**
- 不确定时：在 IXD §4 表「备注」列说明挂载的父级 `P-xx`

### Pattern（可选，不单独前缀）

列表行、详情布局、向导步骤等 **复用型布局**，写在对应 `P-/H-/V-` 章节内标注即可；不强制 `PT-` 前缀。若项目需要可扩展文档，默认不新增字母前缀。

## ID 格式

- 基本形：`<前缀><两位序号>`，如 `P-01`、`H-02`
- 叠加层变体：`<前缀><序号><小写字母>`，如 `O-03a`、`O-03b`
- 全文 **大小写一致**；IXD、ui-plan、HTML 文件名、Pixso Frame 名 **同一字符串**

## 文件与 HTML 命名

- HTML：`docs/design/html/<ID>-<slug>.html`（例 `P-01-home.html`、`O-01-bottom-sheet.html`）
- 导入 Pixso 后：根 Frame **重命名**为 ID（如 `P-01-home`）
- HTML 根 `class` 可用 slug，**导入后以 ID 为准**

## 出图顺序（推荐）

1. `DS-*`  
2. `P-*`（主流程路由屏）  
3. 对应 `H-*` / `V-*`  
4. `O-*`  
5. `G-*`
