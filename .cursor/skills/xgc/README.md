# xgc

项目本地设计流水线 skills；`ags sync` 不会覆盖本目录。

| Skill | 说明 |
| ----- | ---- |
| `xgc-prd-to-ixd/` | PRD → 中文 IXD |
| `xgc-ixd-to-ui-plan/` | PRD + IXD → ui-plan |
| `xgc-ui-plan-to-pixso/` | ui-plan 单帧 → HTML → Pixso |

帧 ID 统一使用 **P/H/V/O/G/DS** 前缀，见 `references/frame-id-convention.md`。

在对话中点名 skill（如 `xgc-prd-to-ixd`），或读取 `xgc/_INDEX.md` 按关键词加载。
