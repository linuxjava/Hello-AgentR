# frontend-admin

Hello-AgentR Web 管理后台。技术选型见 [`docs/frontend-admin/技术方案/技术选型.md`](../docs/frontend-admin/技术方案/技术选型.md)。

## 开发

```bash
npm install
npm run dev
```

## 脚本

| 命令 | 说明 |
| ---- | ---- |
| `npm run dev` | 本地开发 |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run lint` | ESLint |
| `npm run test` | Vitest |
| `npm run preview` | 预览生产构建 |
