# Web 管理端版本更新指引

> 本文件位于 `docs/frontend-admin/版本迭代/` **根目录**，用于检索历史迭代、新增版本目录时遵循统一约定。  
> 总入口见 [Web 管理端文档目录索引](../Web管理端文档目录索引.md)。

## 目录用途

`版本迭代/` 只放**按版本归档的交付物**（该版本当时的 PRD、交互说明、Pencil 稿等）。  
当前生效的工程约定、屏态词汇**不**写在此处，避免与现行文档重复：

| 现行文档 | 路径 | 说明 |
| --- | --- | --- |
| 工程架构 | [../工程架构.md](../工程架构.md) | 目录分层、路由、依赖、启动 |
| 领域词汇 | [../CONTEXT.md](../CONTEXT.md) | 屏态 / 交互边界 |
| 后端 API | [../../backend/api.md](../../backend/api.md) | 管理端消费的 HTTP 契约 |
| 后端词汇表索引 | [../../backend/CONTEXT.md](../../backend/CONTEXT.md) | 指向各上下文 |
| 后端身份词汇 | [../../backend/context/admin-identity/CONTEXT.md](../../backend/context/admin-identity/CONTEXT.md) | AdminUser / 角色 / 能力矩阵 |
| 后端知识库词汇 | [../../backend/context/knowledge/CONTEXT.md](../../backend/context/knowledge/CONTEXT.md) | KnowledgeBase（V0.2） |

## 目录约定

```text
docs/frontend-admin/版本迭代/
├── 版本更新.md          # 本指引（勿挪到 vx.y 子目录）
├── v0.1/               # 某一版本的归档
│   ├── prd.md
│   ├── ixd.md
│   └── ui/
└── v0.2/               # 下一版本（示例）
    └── prd.md
```

- 版本目录名：与本端现有归档一致，使用 **`v主.次`**（小写 `v`），例如 `v0.1`、`v0.2`。
- 每个版本目录内放该版本**当时**的需求与设计稿；不要把现行工程架构再抄一份进来。
- 新增版本时：先建目录 → 放入 PRD / IXD 等 → 在下方「已发布版本」表补一行 → 必要时更新 [Web 管理端文档目录索引](../Web管理端文档目录索引.md)。
