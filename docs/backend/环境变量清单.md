# 环境变量清单（backend/app）

> 最后更新：2026-08-13

## 适用范围

- 配置文件：`backend/app/src/main/resources/application.yaml`
- 目标：统一团队在本地、测试、生产环境的连接配置方式

## 变量总览

| 变量名 | 必填 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `DB_HOST` | 是 | `127.0.0.1` | PostgreSQL 主机地址 |
| `DB_USERNAME` | 是 | `postgres` | PostgreSQL 用户名 |
| `DB_PASSWORD` | 是 | `postgres@Xiao123456` | PostgreSQL 密码 |
| `REDIS_HOST` | 是 | `127.0.0.1` | Redis 主机地址 |
| `REDIS_PASSWORD` | 是 | `redis@Xiao123456` | Redis 密码 |
| `ALIBAILIAN_API_KEY` | 否 | 空 | 百炼 Embedding Provider 密钥占位（V0.3，允许为空） |
| `SILICONFLOW_API_KEY` | 否 | 空 | 硅基流动 Embedding Provider 密钥占位（V0.3，允许为空） |
| `S3_ENDPOINT` | 否 | `http://127.0.0.1:9000` | ObjectStorage `type=s3` 时的 endpoint |
| `S3_BUCKET` | 否 | `hello-agentr-knowledge` | S3 / MinIO 桶名；首次上传时若不存在会自动创建（需建桶权限） |
| `S3_REGION` | 否 | `us-east-1` | S3 region |
| `S3_ACCESS_KEY` / `S3_SECRET_KEY` | 否 | 空 | S3 密钥；空则进程可启动，上传/删对象失败 |
| `OSS_ENDPOINT` / `OSS_BUCKET` / `OSS_ACCESS_KEY` / `OSS_SECRET_KEY` / `OSS_INTERNAL_ENDPOINT` | 否 | 空 | OSS 子块占位；`type=oss` 本阶段启动失败 |

## 本地开发

1. 复制模板文件：

```bash
cd backend/app
cp .env.example .env
```

2. 修改 `.env` 中的密码为个人本地值。
3. 启动应用前，确保这些变量已被系统或启动脚本导出。

## 部署建议

- 不要把真实密码提交到仓库。
- 生产环境在部署平台（如 CI/CD、容器编排平台）配置同名变量。
- 建议定期轮换数据库与 Redis 密码。
- 管理端 Bootstrap 初始账号见 [V0.1 PRD](版本迭代/V0.1/prd.md) / [API 文档](api.md)；首次登录后请立即修改密码。
