# 后端版本更新指引

> 本文件位于 `docs/backend/版本迭代/` **根目录**，用于检索历史迭代、新增版本目录时遵循统一约定。  
> 总入口见 [后端文档目录索引](../后端文档目录索引.md)。

## 目录用途

`版本迭代/` 只放**按版本归档的交付物**（该版本当时的 PRD、交互/设计稿、专项说明等）。  
当前生效的工程约定、API 契约、环境变量、领域词汇**不**写在此处，避免与现行文档重复：

| 现行文档   | 路径                             | 说明          |
| ------ | ------------------------------ | ----------- |
| 工程架构   | [../工程架构.md](../工程架构.md)       | 模块、分层、依赖、启动 |
| API 契约 | [../api.md](../api.md)         | 当前 HTTP 接口  |
| 环境变量   | [../环境变量清单.md](../环境变量清单.md)   | 连接配置        |
| 领域词汇索引 | [../CONTEXT.md](../CONTEXT.md) | 指向各上下文词汇表   |
| Admin Identity 词汇 | [../context/admin-identity/CONTEXT.md](../context/admin-identity/CONTEXT.md) | V0.1 引入，持续生效 |
| Knowledge 词汇 | [../context/knowledge/CONTEXT.md](../context/knowledge/CONTEXT.md) | V0.2 引入，持续生效 |

## 目录约定

```text
docs/backend/版本迭代/
├── 版本更新.md          # 本指引（勿挪到 Vx.y 子目录）
├── V0.1/               # 某一版本的归档
│   └── prd.md
└── V0.2/
    └── prd.md
```

- 版本目录名：`V主.次`，例如 `V0.1`、`V0.2`（与 OpenSpec / PRD 中的版本号一致）。
- 每个版本目录内放该版本**当时**的需求与专项文档；**不要**把词汇表放进版本目录（词汇表按上下文放在 `docs/backend/context/`）。
- 新增版本时：先建目录 → 放入 PRD 等 → 在下方「已发布版本」表补一行 → 必要时更新 [后端文档目录索引](../后端文档目录索引.md)。
