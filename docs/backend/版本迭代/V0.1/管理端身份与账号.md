# 管理端身份与账号（V0.1）

> 对应 OpenSpec：`openspec/changes/add-admin-user-auth`  
> 领域词汇：`docs/backend/CONTEXT.md`

## 前置条件

1. PostgreSQL / Redis 可用（见[环境变量清单](../环境变量清单.md)）
2. 手工执行建表脚本：

```bash
psql -h "$DB_HOST" -U "$DB_USERNAME" -d hello-agent -f backend/app/src/main/resources/db/t_admin_user.sql
```

## Bootstrap Admin

应用启动时若尚不存在 `bootstrap=true` 账号，将自动创建：

| 项 | 值 |
| --- | --- |
| 用户名 | `admin` |
| 初始密码 | `admin@123456` |
| 角色 | `ADMIN` |

**请登录后立即修改密码。** 若用户名 `admin` 已被非 bootstrap 账号占用，启动会失败。

## API 前缀

上下文路径以 `application.yaml` 为准（当前 `/hello/agentr`）。示例：

- `POST /hello/agentr/admin/auth/login`
- `GET /hello/agentr/admin/auth/me`（请求头 `Authorization: <token>`）
- `GET /hello/agentr/admin/users`

完整端点见 OpenSpec `design.md`。
